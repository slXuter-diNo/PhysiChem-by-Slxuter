# PhysiChem 🔬⚛️

**PhysiChem — Physics & Chemistry Explorer**

An interactive educational website designed to make Physics and Chemistry easier and more interesting through **3D models, visualizations, and interactive learning tools**.

## ✨ Features

* ⚛️ Interactive 3D Atom Models
* 🧪 3D Molecule Models
* 📚 Physics & Chemistry Topics
* 🔬 Periodic Table
* ➕ Criss-Cross Formula Generator
* 💻 Responsive website for desktop and mobile

## 🛠️ Built With

* HTML
* CSS
* JavaScript
* Three.js

## 🎯 Goal

To create an interactive way for students to explore and understand Physics and Chemistry concepts visually.
